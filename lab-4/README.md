## Требования к лабораторной работе

### Цель работы

Изучить основы разработки серверного web-приложения с использованием Node.js, Express и стандартного модуля http

### Задачи лабораторной работы

1. Реализовать маршрут для отображения HTML-страницы с таблицей.
2. Реализовать хранение данных в памяти сервера (массив объектов).
3. Реализовать добавление новых записей в таблицу через HTML-форму.
4. Реализовать удаление записей из таблицы по идентификатору.
5. Использовать HTTP-методы GET и POST.

### Пример:

6. Установить Node.js (https://nodejs.org/)
7. Скачать пример (https://github.com/elenanga/express_example.git)
8. Установить модули ( npm install )
9. Запустить сервер( node server.js)
